# LeetCode Practice Problems

This directory contains interview preparation problems converted from study notes.

## Completed Problems

1. **collatz_conjecture.py** - Collatz Conjecture problem with memoization
2. **queue_limited_size.py** - Design Queue with Limited Size of Array
3. **vector2d.py** - Flatten 2D Vector (LeetCode #251)
4. **nested_list_iterator.py** - Flatten Nested List Iterator (LeetCode #341)

## Problem Template

Each problem file follows this structure:
- Problem statement with examples
- Interview-style explanation (why this approach?)
- Solution class with type hints
- Test cases
- Example usage

## To Add More Problems

1. Extract problem from PDF/notes
2. Create new file following the template
3. Include:
   - Problem statement
   - Interview explanation
   - Solution code
   - Test cases
   - Example usage

## Running Problems

Each file can be run directly:
```bash
python leetcode/problem_name.py
```
