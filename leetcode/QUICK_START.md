# Quick Start Guide

## 🚀 Getting Started with Interview Prep

### What You Have
- **31 problem files** with full interview prep format
- **Algorithm guide** covering Airbnb's most common patterns
- **Action plan** with prioritized next steps

### How to Use

1. **Review Algorithm Guide First**
   ```bash
   cat AIRBNB_INTERVIEW_GUIDE.md
   ```
   Understand the patterns Airbnb asks most (DP, Graph, String)

2. **Practice Problems by Pattern**
   - Start with DP: `house_robber.py`, `edit_distance.py`, `maxsquare.py`
   - Then Graph: `aliendictionary.py`, `word_search_ii.py`, `cheapest_flights_k_stops.py`
   - Then String: `csv_parser.py`, `text_justification.py`, `palindrome_pairs.py`

3. **Run and Test**
   ```bash
   python leetcode/house_robber.py
   ```

4. **Study Strategy**
   - Week 1: Master DP patterns
   - Week 2: Master Graph algorithms
   - Week 3: Practice real-world problems (Travel Buddy, Pagination)
   - Week 4: Mock interviews
